Polecenia git

Poniższe polecenia są niezbędne przy pracy z użyciem gita.

polecenie przyklad opis
git clone git clone URL Pobiera repozytorium i tworzy lokalny katalog
git status git status Sprawdza gałęzie oraz pliki przygotowane i zmienione
git add git add docs/warp/git.md Dodaje wyznaczony przez nas plik do obszaru staging
git commit git commit -m "docs: add Git cheatsheet" Zapisuje przygotowanie zmiany z czytelnym komunikatem
git push git push -u origin feature/git-cheatsheet Publikuje nową gałęź i ustawienie śledzenia
git pull git pull -u origin feature/git-cheatsheet Pobiera zmian bez tworzenia nieoczekiwanego merge commita
git fetch git fetch origin Pobiera informacje o zmianach bez modyfikowania pliki roboczych
git branch git branch Wyświetla lokalne gałęzie i oznacza aktywną
git switch git switch -c feature/nazwa Tworzy gałąź roboczą i przełącza nas na nią
git log git log --oneline -5 Pokazuje skrócony podgląd 5 ostatnich commitów

Procedura pracy z gitem

  1. synchronizacja
  2. branch
  3. zmiana
  4. commit
  5. push
  6. PR
